# CFT Provisional Decisions

Locked for v0.1.0 implementation (editable via config, not ad-hoc code):

1. **Three rules:** shape, pattern, number (not orientation yet).
2. **Response mapping:** circle/solid/one → Left (F); square/striped/two → Right (J).
3. **Blocks:** practice → rule_learning → predictable_switch → cued_switch → interference.
4. **Primary CFS blocks:** the three switching/interference blocks only.
5. **Error priority:** perseverative > conflict > cue_processing > rule_maintenance.
6. **Themes:** clinical + game; scoring identical.
7. **Admin modes:** supervised_clinical | research | public (RIT parity).
8. **No battery composite** (each subtest scored separately). Administration may auto-handoff GMT → RIT → CFT in a sequenced full battery; that is sequencing only, not a combined EF score.
9. **RIT interference remains inhibition** (reversed mapping), not set-shifting.
